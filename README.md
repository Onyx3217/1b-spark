PROMPT

Tu es un directeur artistique, développeur Front-End senior (Apple + Awwwards + Framer + GSAP) et expert UX/UI.

Crée un site web de campagne IMMERSIF pour deux candidats délégués de classe.

Sujet

Élection des délégués de la classe 1B.

Les candidats sont :

Camille

Léo

Le slogan principal est :

« Ensemble, on fait bouger la 1B. »

Le site doit donner envie de voter pour eux. Il doit être spectaculaire, drôle, moderne, très premium, mais aussi crédible.

STYLE GÉNÉRAL

Awwwards Website of the Year
